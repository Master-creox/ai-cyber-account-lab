# Security Policy

## Scope

AI Cyber Account Lab is an **educational, defensive** security project.
It works only on sample/synthetic data and on inputs you provide locally:

- Passwords are assessed in memory only — never stored, logged or sent anywhere.
- The web dashboard runs on `127.0.0.1` (localhost) and stores nothing.
- The synthetic dataset contains no real user data.

## Reporting a vulnerability

If you find a security issue in this project, please open a GitHub issue
with the label `security`, or contact the maintainer privately via the
GitHub profile. Please do not include real credentials or personal data
in a report.

## Supported versions

Only the latest commit on the `main` branch is supported.
