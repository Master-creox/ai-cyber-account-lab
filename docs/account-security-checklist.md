# Account Security Checklist

Use this checklist for your own accounts.

## Passwords
- [ ] Every important account has a unique password
- [ ] Passwords are long passphrases (14+ characters)
- [ ] Passwords are stored in a password manager, not in notes or chats
- [ ] No password is shared or reused after a known leak

## Two-factor authentication (2FA)
- [ ] 2FA is on for email, banking, and social accounts
- [ ] Prefer an authenticator app or security key over SMS where possible
- [ ] Backup / recovery codes are saved offline in a safe place

## Recovery & sessions
- [ ] Recovery email and phone number are current
- [ ] Unknown logged-in devices / sessions are reviewed and removed
- [ ] Account activity / login alerts are turned on where available

## Phishing awareness
- [ ] Sender address and domain are checked before clicking or logging in
- [ ] Links are opened from the official app/site, not from urgent messages
- [ ] Unexpected attachments and login pages are treated as suspicious
